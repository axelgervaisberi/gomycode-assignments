# React Hooks Checkpoint - Movie App

A React Movie App built using React Hooks (`useState`), featuring `MovieCard`, `MovieList`, `Filter` (title search & rating threshold), and `AddMovie` form modal.

## Features

- **MovieCard Component**: Displays movie details (title, description, posterURL, rating stars).
- **MovieList Component**: Renders a responsive grid of `MovieCard` components.
- **Filter Component**: Allows users to filter movies by title and rating dynamically.
- **AddMovie Component**: Modal form enabling users to add new movies to the state.
- **React Hooks**: Built using functional components and `useState`.

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm start
   ```

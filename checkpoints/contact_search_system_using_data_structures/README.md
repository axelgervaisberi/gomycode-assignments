# Contact Search System Using Data Structures

A simple contact management system built with Node.js using data structures.

## Data Structures Used

- **Doubly Linked List**: Stores contacts and lets us display them forward and backward.
- **Hash Table**: Stores contacts by name for quick lookup.
- **Naive Substring Search**: Performs substring matching to search contacts by keyword.

## How to Run

Run the app:
```bash
node index.js
```

Run tests:
```bash
node test.js
```

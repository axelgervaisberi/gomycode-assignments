# Graph Basics and Traversal

JavaScript implementation of a Graph data structure using an adjacency list, with support for directed/undirected graphs, DFS, and BFS.

## Features

- **Adjacency List**: Built using JavaScript `Map`.
- **Graph Operations**: `addVertex`, `addEdge`, `removeEdge`, `hasEdge`, `printGraph`.
- **Traversals**:
  - `dfs(startVertex)`: Depth-First Search traversal.
  - `bfs(startVertex)`: Breadth-First Search traversal.
- **Graph Types**: Supports both directed and undirected graphs via the `isDirected` flag in the constructor.

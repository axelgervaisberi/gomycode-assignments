# React Checkpoint 01

A React application displaying a product card built with modular components (`Name`, `Price`, `Description`, `Image`), React-Bootstrap, and conditional user greeting logic.

## Project Architecture

- `src/product.js`: Product JSON object.
- `src/components/Name.js`: Displays product name.
- `src/components/Price.js`: Displays product price.
- `src/components/Description.js`: Displays product description.
- `src/components/Image.js`: Displays product image.
- `src/App.js`: Root component combining product components inside a React-Bootstrap Card and handling conditional user greetings & avatar.

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm start
   ```

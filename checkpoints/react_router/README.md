# React Router Checkpoint - Movie App Routing

A React Movie App with multi-page navigation using `react-router-dom` v6, featuring embedded YouTube trailers, detailed movie description pages, and a "Back to Home" navigation button.

## Features

- **React Router Navigation**: Uses `BrowserRouter`, `Routes`, `Route`, `Link`, and `useParams`.
- **Movie Details View**: Dedicated route (`/movie/:id`) rendering complete movie description and embedded YouTube trailer iframe.
- **Back to Home**: Easy navigation returning users to the main movie library page.
- **Card Click Navigation**: Every movie card links directly to its detail page.

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm start
   ```
